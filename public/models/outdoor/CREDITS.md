# Outdoor garden models

All models are from [Poly Haven](https://polyhaven.com) and released under **CC0** (public domain). `npm run build:outdoor` repacks the 1K glTF downloads into these GLBs. It keeps only the lighter foliage variants, folds each foliage Alpha map into its colour map, and downsizes textures.
