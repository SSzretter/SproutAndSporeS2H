# Surface textures

All textures are from [Poly Haven](https://polyhaven.com) and released under **CC0** (public domain). Each folder holds the colour map (1024 px), an OpenGL normal map and an ARM map (AO, roughness, metalness; 512 px), resized by `npm run build:textures`.
